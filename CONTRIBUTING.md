# Contributing to GrooveBox888

Thanks for helping improve **GrooveBox888** — a **free, open-source** (MIT) project.

## Before you start

1. Read [`QUICKSTART.md`](QUICKSTART.md) and run **`bash scripts/run-groovebox-checks.sh`** before opening a PR (or explain why checks do not apply).
2. Follow [`docs/dev/WORKFLOW.md`](docs/dev/WORKFLOW.md): scratch in **`.local/`**, intent in **`TASKS.md`**, replaced trees in **`.compost/`** when appropriate.
3. Match existing style in the folders you touch; avoid unrelated refactors.

## Pull requests

- Prefer **small**, reviewable changes with a clear **what / why** in the PR description.
- Do not commit secrets, API keys, or machine-specific absolute paths in tracked docs (see `scripts/run-groovebox-checks.sh` hygiene).

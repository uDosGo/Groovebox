# Config

This directory is reserved for checked-in, non-secret Groovebox configuration
examples such as synth defaults, export profiles, and pattern rendering presets.

- **`groovebox-library.example.json`** — example overlay for **`UDOS_LIBRARY_DIR`** / **`GROOVEBOX_AUDIO_ROOT`** (see [`docs/DISTRIBUTION.md`](../docs/DISTRIBUTION.md)).

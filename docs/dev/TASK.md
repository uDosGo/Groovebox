# Task format (GrooveBox888)

Same checkbox protocol as **[Linkdown `docs/TASK.md`](https://github.com/fredporter/Linkdown/blob/master/docs/TASK.md)** (Task Forge): sections **Backlog**, **In Progress**, **Blocked**, **Done**; optional IDs like `[GB-010]`; metadata lines with `↳` under tasks.

Keep free-form notes out of `TASKS.md` — use **`.local/`** instead.
